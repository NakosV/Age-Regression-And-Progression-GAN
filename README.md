# Age Regression And Progression GAN
A Facial Age Trasformation Conditional-GAN featuring an Encoder-Decoder architecture to perform age Regression and Progression, built from scratch in Python as part of a university course assignment.

# Contents of this Project  
This repository contains the code of the project which is the following file:
- **[`Conditional-GAN.py`](Conditional-GAN.py)**  

# Some words about the program
Unlike other GANs, this model doesn't just generate random faces. It has been specidically built to take the face of someone and show it in different age groups. In order to insure that happened I had to utilize an Encoder-Decoder architecture along with Spectral Normalization and custom data sampling. If you want to take a look under the hood and learn about the inner workings of the code in more detail **[you can click here.](DETAILS-ABOUT-THE-CODE.md)**
